一款轻量、零数据库的局域网私有云网盘系统，基于 PHP 与 JSON 文件存储，支持目录权限管控、分片大文件上传、快递取件码提取及在线多媒体预览。

## 一、 功能

1. **零数据库运行**
   - 所有目录配置、文件记录与留言数据均保存在 `data/metadata.json` 中，物理文件存放在 `uploads/` 对应子目录下，易于备份与迁移。
2. **精细化目录权限**
   - 支持**直接打开**与**密码访问**两种开启方式。
   - 可独立配置访客直接打开时的权限（查看、下载、上传）以及密码解锁后的权限（下载、上传、管理）。
   - 支持设置单目录总容量上限、单文件大小上限与允许上传的文件后缀白名单。
3. **分片大文件上传**
   - 支持多文件队列顺序上传，自动以 3MB 为单位进行切片传输并在服务端合并，突破常规 PHP 表单大小限制，实时显示单文件及总队列进度。
4. **快递取件码与分享**
   - 上传文件或添加外部链接后自动生成 5 位取件码（如 `X6666`）。
   - 访客在左侧取件框输入取件码或打开分享链接，可直接提取文件，不受目录权限限制。
5. **在线多媒体与文本预览**
   - 支持图片缩放、旋转与拖拽预览（支持同目录上下张切换）。
   - 支持常见视频（`mp4`、`webm` 等）、音频（`mp3`、`wav`、`m4a` 等）在线播放，以及纯文本与代码文件预览。
6. **系统安全防护**
   - 管理员可配置全局强制禁止上传的文件后缀黑名单，上传与重命名环节双重拦截高危可执行脚本。

## 三、环境要求

- **运行环境**：PHP 7.4 及以上版本（需开启 `json`、`session` 扩展）
- **目录结构**：
  ```text
  ├── index.php          # 前端主界面
  ├── backend.php      # 后端接口与文件处理
  ├── styles.css          # 页面布局样式
  ├── js.js                 # 页面js
  ├── img/                 # 目录与锁状态图标
  ├── data/                # 自动生成，存放配置文件
  └── uploads/           # 自动生成，存放上传文件
  ```
- **目录权限**：确保 Web 运行用户对 `data/` 和 `uploads/` 目录拥有读写权限。

## 四、 快速上手

### 1. 登录管理员模式
- 首次部署请先从服务器本地 data/initial-admin-password.txt 获取随机初始密码；首次登录后该文件会自动删除。登录后请立即设置自己的强密码。。
- 在左侧选项卡切换到 **管理区**，输入密码进入管理员模式。
- 首次登录后建议立即修改管理密码，并检查系统强制禁止文件类型设置。

### 2. 创建与配置目录
- 管理员在 **增加目录** 选项卡中填写目录标题、备注、开启方式、权限勾选项及容量/后缀限制，点击确认新增。
- 在右侧目录列表点击目录名称可展开内容（同一时间仅展开一个目录），拥有管理权限时可点击 **编辑** 调整目录属性。

### 3. 取件码提取与文件管理
- 在左上角 **快递取件查询** 输入取件码即可弹窗下载或复制分享链接。
- 拥有目录管理权限的用户可对文件执行改取件码、跨目录迁移、重命名、删除及查看操作/下载日志。

## 五、 上线安全建议

1. 务必修改默认管理员密码 。
2. 在 Web 服务器配置中禁止外部直接访问 `data/` 目录（防止直接下载 `metadata.json`），并禁止 `uploads/` 目录执行任何脚本文件。
